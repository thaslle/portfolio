# Thalles Lopes Portfolio

Thalles Lopes's portfolio from 2025.

# Overview

My previous portfolio felt a bit outdated, so I decided to build something fresh
that reflects my evolving interests, particularly in 3D development. This new
website allows me to give more emphasis to these passions, using videos and
WebGL effects to bring my work to life. I wanted to strike a balance between
design and development, showcasing my personal projects where I have the freedom
to let creativity run wild. At the same time, I aimed to demonstrate the broad
range of skills I’ve developed—from architecture and illustration to 3D
design—giving people a glimpse into the diverse ways I approach each project.

This website is built with [Next.js](https://nextjs.org/), using
[Lenis](https://lenis.darkroom.engineering/) for smooth scrolling,
[Motion](https://motion.dev/) (formerly Framer Motion) for animations, and
[React Three Fiber](https://r3f.docs.pmnd.rs/) for the 3D environment.
